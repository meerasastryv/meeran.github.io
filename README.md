# Meera Sastry — Portfolio

Personal portfolio site for Meera Sastry, Technology & Quality Engineering Leader (AI-enabled QA, GenAI/RAG, test automation).

Static HTML/CSS/JS, served by GitHub Pages — no build step.

- `index.html` — the portfolio
- `assets/` — styles, script, favicon, social preview image and résumé PDF
- `resume/resume.html` — source of the résumé PDF; regenerate with
  `google-chrome --headless=new --no-pdf-header-footer --print-to-pdf=assets/Meera_Sastry_Resume.pdf resume/resume.html`
